# Killer Instinct Gold Decompilation

An unofficial, work-in-progress fan decompilation of *Killer Instinct Gold* (Nintendo 64, USA V1.2), for research and preservation.

**This repository contains no game code or assets. You must supply your own legally obtained copy of the game to build it.**

Not affiliated with or endorsed by Nintendo, Rare, or Microsoft.

## Status

Early setup. See `PLAN.md` for the roadmap.

## Building

Not buildable yet. Instructions will be added once the ROM split and build system exist.

## Contributing

This repository never accepts the ROM, extracted assets, generated code, or leaked material. A commit guard (`tools/guard.py`) enforces this.
